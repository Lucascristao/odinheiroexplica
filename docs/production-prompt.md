# Pedido reutilizável

Copie o texto abaixo para uma IA com acesso ao checkout e ao GitHub deste projeto.

> Gere o vídeo de hoje do O Dinheiro Explica. Pode escolher a pauta: consulte todos os vídeos no histórico e escolha um assunto inédito com conflito real no bolso, fontes verificáveis e potencial de curiosidade. Leia AGENTS.md, frame.md e skills/ode-video/SKILL.md; siga as demais skills indicadas. Pesquise, registre storyboard, escreva video/data/daily.json e use os recursos implementados do motor, incluindo HyperFrames quando ajudar a demonstração. Execute o modo normal com verificações, commit e push na main; aguarde CI do mesmo commit e dispare a produção real. Acompanhe voz, alinhamento, render e envio, corrija falhas preservando cache e confira o MP4 com áudio. Gere a capa completa, confirme vídeo, título, descrição, capa e pacote de revisão na mesma pasta do Drive. Registre pesquisa e entrega no Git e devolva o link da pasta com limitações reais. Iniciar Actions não conclui o pedido. Publicação no YouTube é manual.

> Ao confirmar o pacote completo no Drive, conclua a limpeza automática conforme docs/production-portable.md. Baixe artifacts em work/runs/ID e envie capa e revisão com npm run ode -- deliver. Se concluir pelo conector, registre o recibo e execute npm run ode -- complete --production production/ID-DO-EPISODIO. Não mantenha arquivos temporários locais de vídeo, áudio, testes e revisão após a entrega; preserve código e registros definitivos no Git.

Para gerar uma variante, use npm run ode -- prompt --request "Seu pedido". --ask-topic solicita três opções; --direct exige intenção explícita de produção sem testes. A autoria é independente do fornecedor de IA; a síntese de voz segue a política canônica do canal.
