# Capturas de fontes

Guardar aqui imagens autênticas capturadas durante a pesquisa para uso como `source_excerpt`. Vincular cada arquivo a `visual_assets` e `sources`, conforme `docs/editorial-evidence.md`. Usar nomes simples sem dados pessoais, salvar o arquivo antes de disparar o render e preservar a captura original. Não adicionar exemplos fictícios de notícias ou arquivos temporários com sessão autenticada, notificações ou informações privadas.
